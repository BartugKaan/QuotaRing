# QuotaRing v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A trustworthy open-source macOS menu bar app that shows the remaining 5-hour Claude limit as a ring and a detailed usage popover on click.

**Architecture:** All logic lives in a dependency-free Swift package `QuotaRingCore` (`Core/`), unit-tested with Swift Testing and runnable via `swift test` without Xcode. The app target (`App/`, generated by XcodeGen from `project.yml`) is a thin AppKit + SwiftUI layer: an `NSStatusItem` with a drawn ring, an `NSPopover` hosting SwiftUI, a Settings scene, and an `AppModel` that orchestrates three read-only sources (Claude Code's cached snapshot, opt-in live endpoint, local transcripts).

**Tech Stack:** Swift 6.2 (language mode 6, complete concurrency checking), SwiftUI, AppKit, Swift Charts, Security.framework, CryptoKit, UserNotifications, ServiceManagement, Swift Testing, XcodeGen, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-20-quotaring-design.md` (read it; this plan argues from it).

## Global Constraints

- Deployment target macOS 14.0; universal binary; Swift language mode 6; `SWIFT_STRICT_CONCURRENCY = complete`.
- No third-party runtime dependencies. Dev tools only: XcodeGen (Homebrew), bundled `swift format`.
- Bundle id `io.github.bartugkaan.QuotaRing`; `MARKETING_VERSION 0.1.0`; `LSUIElement YES`; Hardened Runtime on; not sandboxed.
- Only network host: `api.anthropic.com`. Endpoint constant `https://api.anthropic.com/api/oauth/usage`; headers `Authorization: Bearer <token>`, `anthropic-beta: oauth-2025-04-20`, `Accept: application/json`, `User-Agent: QuotaRing/<version> (+https://github.com/BartugKaan/QuotaRing)`.
- Never write, refresh, persist, log or print an OAuth token; never write `~/.claude.json`, `~/.claude/**` or Keychain items; never launch the `claude` CLI.
- Refresh interval default 300 s, options 180/300/600/900 s, jitter ±10 %, back-off 2× per failure capped at 1800 s, manual refresh cooldown 60 s, cache `stat` every 30 s, cache file max 50 MB, transcript line max 10 MB.
- Ring tint: remaining ≤ 20 % orange, ≤ 5 % red. Default notification thresholds 80 and 95 (% used); reset notice default off.
- `limits[].percent` and legacy `utilization` are **percent used**, 0–100. Remaining = 100 − used.
- English is the base language; Turkish added in Task 13. All user-facing strings via `String(localized:)` / `LocalizedStringKey`.
- Formatting: `swift format` with the repo `.swift-format` (4-space indent, 120 columns). Tests: `import Testing`, `@Test`, `#expect`.
- Subagents must not read `~/.claude*`, the Keychain or any credential; use fixtures. Live checks are done by the lead only.
- Commits: Conventional Commits, each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Claude Code rewrites `~/.claude.json` while we read it (truncated/invalid JSON) → reader throws `.malformed`, app keeps the previous snapshot; never shows 0 % because of a bad read. (Task 2 test `truncatedFileThrowsMalformed`; Task 7 keeps last snapshot on error.)
2. Snapshot older than its `resets_at` (laptop slept through the reset) → session shown as 0 % used, "waiting for fresh data", never the stale percentage. (Task 6 test `sessionResetsWhenResetTimePassed`.)
3. `resets_at` jitters by sub-seconds between fetches (`22:50:00.192966` vs `22:49:59.972394`) → same window; threshold notifications must not fire twice. (Task 6 test `jitteredResetTimeIsSameWindow`.)
4. Transcript timestamps are UTC (`2026-10-20T20:35:00.527Z`) → grouped by the user's local day (Europe/Istanbul crosses midnight at 21:00Z). (Task 5 test `groupsByLocalDay`.)
5. A transcript file is being appended mid-scan (partial last line) or rotated/truncated → partial line is ignored then picked up next scan; truncation triggers re-read without double counting. (Task 5 tests `partialTrailingLineIsDeferred`, `truncatedFileIsRescanned`.)
